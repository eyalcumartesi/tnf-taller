capa 2/4 · tooling — la caja cian del diagrama

skill · command · subagente · MCP: ¿cuál?

la regla es por forma, no por tamaño:

primitivo✓ úsalo para✗ no para
/commandun prompt que repites una sola instrucción: correr tests, formatear si necesita pasos o archivos → es un skill
skillworkflow multi-paso, auto-carga armar un PR · convenciones del repo · "cómo se corre esto" algo que Claude ya hace bien · docs que cambian seguido
subagentecontexto fresco, en paralelo explorar codebase · research · criticar el diff si no necesita contexto fresco, pagas aislamiento de más
MCPsistema externo, vivo GitHub · base de datos · Playwright solo leer/mostrar → usa web search
en vivo skill crear-pr → .claude/skills/crear-pr/SKILL.md 
---
name: crear-pr
description: Empaqueta cambios en un PR. Usalo cuando el usuario pida abrir o armar un PR.
---

Cuando el usuario pida un PR:

1. git add -A y muestra el diff resumido para confirmar
2. crea una rama nueva descriptiva (feat/..., fix/...)
3. commit con un mensaje claro en imperativo
4. git push -u origin la rama
5. gh pr create con titulo y cuerpo (que cambia y por que)

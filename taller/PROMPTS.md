# prompts del taller

todos los prompts que usé en las demos, listos para copiar.

## 1. critique pattern (el que corrimos al final)
```
Revisa el código que acabas de escribir como si fueras un senior reviewer
que no confía en ti. Lista problemas concretos, ordenados por severidad.
No arregles nada todavía.
```

## 2. corregir con la crítica
```
Corrige el output aplicando cada punto de la crítica. Después lo reviso yo.
```

## 3. e2e con Playwright
```
Escribe un test e2e del login con Playwright: navega a /login, ingresa
credenciales y verifica el redirect al dashboard. Correlo hasta que pase.
```

## 4. review con subagente fresco
```
Usa un subagente para revisar mis cambios contra el plan.
Ve solo el diff y los criterios. Lista problemas concretos por severidad.
No arregles nada todavía.
```

Comandos y setup completo del harness: ver `CHEATSHEET.md`.

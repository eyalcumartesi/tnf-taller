hands-on · Apple Silicon

instala todo — copy · paste

pégalo en orden en Warp. cada bloque tiene su botón copiar.

1Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
2oh-my-zsh
RUNZSH=no CHSH=no sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
3herramientas (una línea)
brew install git gh nvm pnpm ripgrep jq
brew install --cask warp cursor
4node LTS (via nvm)
echo 'export NVM_DIR="$HOME/.nvm"' >> ~/.zshrc
echo '[ -s /opt/homebrew/opt/nvm/nvm.sh ] && . /opt/homebrew/opt/nvm/nvm.sh' >> ~/.zshrc
source ~/.zshrc && nvm install --lts
5Claude Code
npm install -g @anthropic-ai/claude-code
